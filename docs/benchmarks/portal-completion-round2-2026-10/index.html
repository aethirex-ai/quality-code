02 / Track causes, not assertion counts

Repairs, then further findings.

A fresh audit reproduced a post-commit response race in decision and publication endpoints. The persistent builder captured response snapshots under the transaction lock and passed deterministic regressions. A separate repair corrected acknowledged activity display. Trace review records five product correction cycles, one visual refinement, two tooling corrections and a separate checker-driven project switcher.

Review feedback

Stored decisions remain intact, but previous outcomes and the client’s note are not usefully delivered in revision/product views.

Navigation & saves

Leaving and returning before a pending write completes can skip data reconciliation after acknowledgment.

Legal long text

A valid 120-character title produced horizontal overflow at both tested widths. Normal seed-state captures do not show this boundary.

These three later cause clusters have concrete evidence, but the second reviewer submitted no canonical verdict before its cap. They remain open. The control has no comparable independent app audit; more findings do not measure detection recall or prove one model/topology safer.

05 / Reproduce and learn

Local prototypes. Open evidence.

GitHub Pages serves these screenshots; it does not deploy Python or SQLite. Run a copy of the frozen adaptive source with a fresh disposable database:

cd benchmarks/portal-completion-round2-2026-10/apps/adaptive
python3 server.py --host 127.0.0.1 --port 8000 --db /tmp/aeth-client-workspace-demo.sqlite3

The source README lists synthetic accounts, offline checks, evaluator controls and every limitation. The prior schema-rejected preparation attempt remains separate: 285 files retained, $1.2726912 reported completed-builder proxy, rejected-audit and full setup cost unknown. No image generation was used in this code-native portal pair.

The next protocol needs soft stage planning within a hard shared deadline, tested reconnect/cap behavior and an actual child-model selection check. This pair remains unchanged; no better outcome is substituted after grading.
