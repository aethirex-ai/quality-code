# Security

Do not post secrets or exploit details in a public issue. Report a suspected vulnerability privately to **aethdesign@gmail.com** with “Quality Code security” in the subject, affected version or commit, impact, and a minimal reproduction without private data.

No response-time or supported-version guarantee is currently offered. Security fixes target the current main branch.

Verification commands execute local programs with your permissions. Review configuration and detected package scripts before running them. This toolkit is not an execution sandbox, certification, or authorization system. Global installation changes agent instruction and skill files; review and back up those files first.
