# AethDesign: new clients and concrete error finding

**11 October 2026 · Quality Code v3 · One pair per workload**

The revised adaptive delegation kept the website speed advantage: **37.6% less elapsed time**. It did **not** reduce usage against the new single-agent control: input rose **185.1%**, output **16.7%**, and the hypothetical coding API subtotal **52.9%**. Both frozen portfolios passed **58/58 browser checks**.

The separate contract-defect workload was **9.1% slower** with adaptive delegation and its coding API equivalent was **6.2% higher**. Both outputs repaired **8/8 intentionally seeded defects**, preserving **9/9 healthy groups**. Discovery accuracy and additional reports are reviewed separately below; executable fixes alone do not prove finding quality.

Each produced two successful native images per page under the same 20-minute whole-tree allowance. Order was adaptive then single, reversing the first pilot. ## What changed—and what the results support

[The first-pilot diagnosis](DIAGNOSIS.md) identifies repeated full instructions, retained context, duplicated inspections and a small nested helper. Its cheaper helper was not the main monetary driver. The revised policy favors coherent direct owners, the smallest useful team, scoped fresh context, bounded returns and one shared budget. Compact global instructions route to the project policy; visual criteria include mobile composition and content/image fit. This audited policy was published and delivered to 12 working project roots, preserving project configuration and custom instructions.

These observations support using parallel owners when elapsed time matters and independent work is substantial, while retaining single-agent work as a strong default for coupled or token-sensitive tasks. They do not support automatic recursive fan-out, guaranteed quality gains, savings from cheaper models alone, or lower subscription consumption. More context processing can coexist with mostly cached input and modest API-equivalent differences.

Absolute adaptive website usage was below the first pilot, but the new control also used much less. New clients/styles, revised rules, imagery, order and service/cache conditions changed together. No causal policy savings can be claimed. There is one pair per workload, uncontrolled shared-host/service/cache load, an alpha CLI and one qualitative reviewer. A counterbalanced repeated ablation on an unchanged workload would be needed to isolate instruction or topology effects. The honest result includes the remaining overhead.
