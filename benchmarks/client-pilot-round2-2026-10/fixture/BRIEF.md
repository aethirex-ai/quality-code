# AethDesign new-client portfolio brief
Build THREE exceptional, complete and distinctive fictional business landing pages plus a root portfolio index. Same professional portfolio standard as a commissioned AethDesign case; no three recolored copies. All businesses and offers are fictional.

## Clients, visual directions and observable contracts
- `hotel/index.html`: TIDE HOUSE, a boutique coastal hotel. Crisp maritime editorial luxury: ink navy, white, restrained sea-green, elegant spacious type, ocean/interior photography, rooms with illustrative prices, place/story, amenities. Avoid the previous warm-cream craft/store look. Provide local demo `form[data-testid="reservation-form"]`, labeled required name/email/date/guests fields (`name="name"`, `email`, `date`, `guests`, supporting 2 guests), submit and `data-testid="reservation-status"` showing a meaningful demo confirmation after valid input. No real booking.
- `studio/index.html`: VOLT, an independent fitness and movement studio. Bold contemporary sports editorial: electric cobalt, acid yellow, strong grotesk typography, expressive grid, believable class offerings and illustrative pricing, welcoming coaching without health/transformation claims. Local class shortlist: visible button `data-testid="add-class"` increments visible numeric `data-testid="class-count"` from 0 to 1 to 2 on two clicks. No signup/payment.
- `landscape/index.html`: FIELDWORK, a landscape architecture practice. Swiss editorial portfolio: bright white, oxblood/burgundy, precise typography, strong asymmetric project rhythm, garden/landscape photography; residential gardens, public spaces, process. No old joinery imagery. Provide local demo `form[data-testid="estimate-form"]`, labeled required name/email fields (`name="name"`, `email`), submit and `data-testid="estimate-status"` showing a meaningful demo confirmation after valid input. No real enquiry.

## Image and delivery allowance
Native built-in image generation only. TWO successful original editorial photographs per page (hero and supporting), at most THREE attempts per page counting failures/retries. Generate within the timed run; no stock/shared/probe images, screenshot assets or SVG photographic substitutes. Copy originals into each page assets directory. Match the depicted service/content; inspect the returned native image if possible. Do not print full media-tool results or base64: return native media and only the saved file hint/needed metadata. Exact image backend, tokens and quality settings are not exposed; never claim verification of them.
Each owner writes its page `image-attempts.json`: array with page, attempt, success, prompt, output_paths (project-relative). Primary merges these into root `image-manifest.json` with one record per attempted call including failures. Original and display derivative are one generation.

## Product quality and constraints
Complete persuasive page progression: subject, concrete offers/projects, relevant story/process, appropriate CTA; no fabricated reviews/awards/certifications/customer results. Cohesive typography and readable contrast. Hero/supporting imagery must actually fit its caption/offer. On mobile, avoid excessively tall decorative imagery, compressed paired form fields, clipped controls or weak content rhythm. Meaningful local img alt text, title/description, exactly one h1, semantic main/nav/footer, visible keyboard focus, labeled forms, reduced motion if animated. No overflow at 375/1440px. Meaningful demo confirmations; form inputs never interpolated as HTML.
Visible `Fictional portfolio concept by AethDesign` attribution on every page. System fonts/local assets only. No external scripts/fonts/analytics, backend, APIs, real submissions, installation, commits, deployment or account changes. Keep CSS/JS/assets/tests within the page owner directory; primary owns root index/merged manifest. Preserve BRIEF/MAP/TESTING and managed quality files.
Use applicable runtime instructions without dumping repeated whole documents. Owners finish their complete page including simple interactions and focused checks; use direct helpers by default and recursion only for substantial independent work. Do useful primary work while helpers run. Reserve integration/quality time. Run proportionate checks and inspect representative rendered desktop/mobile states when tools permit; report sandbox/browser gaps explicitly. Frozen evaluator is outside your workspace and must not be inspected. Node: BENCHMARK_NODE. Playwright: BENCHMARK_PLAYWRIGHT_IMPORT.
Shared TOTAL 20-minute wall time across all descendants includes image generation, implementation, validation and coordination; no extra allowance per branch. Final return: paths, checks/limits, actual delegation/model/context choices. No human follow-up.
