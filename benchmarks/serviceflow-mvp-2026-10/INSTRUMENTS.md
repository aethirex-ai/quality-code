# ServiceFlow public instruments

This is a portable publication of the amended measured instruments, common task and blank fixture. The package also includes explicitly projected initial and accepted app sources; it contains no raw native transcripts. `protocol.json` is the provenance map: `native_frozen_sources_sha256` preserves the measured amended freeze; `frozen_sources_sha256` identifies public bytes; `portable_adaptations` lists every changed instrument with both hashes. `native_protocol_sha256` identifies the private amended protocol without publishing host paths. All 24 fixture files retain exact bytes, including the common visual reference.

Run offline checks from this directory:

```
python3 -B -m unittest discover -s . -p 'test_*.py' -v
python3 -B preview/tests.py Contracts
```

Process controls require host process inspection, Node, `lsof` and temporary loopback binding. The real native parser probe is skipped unless `SERVICEFLOW_NATIVE_CLI` is explicitly set; it invokes `--help` only. No test launches a model. Browser integration additionally requires Playwright and Chromium; set `PREVIEW_NODE` and `PREVIEW_PLAYWRIGHT_MODULE` as needed. These tests validate instrumentation, not ServiceFlow acceptance.

A separately authorized new trial can resolve `SERVICEFLOW_NATIVE_CLI` (default PATH discovery of `codex`) and `SERVICEFLOW_SESSIONS_DIR` (default home `.codex/sessions`). `seal.py` initializes the blank fixture Git repository and prepares new condition workspaces; it changes protocol hashes and is not a replay of recorded outcomes. `run.py` and `continue.py` execute native work only when explicitly called. Continuation also supports `SERVICEFLOW_BENCHMARK_ROOT` and `SERVICEFLOW_AMENDMENT_AUDIT`; its public controller defaults to this directory, and its node/Playwright defaults use the normal environment. Sleep prevention is optional on systems without `caffeinate`.
