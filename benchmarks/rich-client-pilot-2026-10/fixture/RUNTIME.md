# Available local runtime and generic rendered previews
Node: node
Playwright: playwright
No dependency installation needed. Primary parent has started a fixed-root preview broker before your timer. Do not launch Chromium directly or weaken permissions.
Client inside this workspace: `python3 preview_client.py --ready`; `python3 preview_client.py --page lighting/index.html --viewport 375` (1440 also supported).
Inspect the returned screenshot using native image/file tools, not just JSON. For interaction states, create a workspace-relative actions JSON file <=4KiB and pass `--actions-file relative.json`. At most12 actions: click/fill/select/check/press/scroll with a CSS selector, fill/select value, press key Tab/Escape/Enter. No arbitrary JS/URL/evaluator is accepted. A complete local sequence can click between client pages, edit inputs, inspect a dialog/form, and render the final state. Example `[{'op':'click','selector':'[data-testid="open-product"][data-product-id="arc"]'}]` must be valid JSON with double-quoted keys/strings in the actual file.
Each preview uses fresh browser state; actions within that request share a context. No browser context persists across requests. Source snapshots and screenshot/diagnostics are generic builder evidence, not hidden grading. Failed actions/errors/overflow and visible defects require honest issue/recheck logs. Bridge captures viewport screenshots; `scroll` with a CSS selector brings lower sections/forms/footer into view. Example: a scroll action for `footer`. No new network/sandbox options required; workspace restrictions remain intact.
