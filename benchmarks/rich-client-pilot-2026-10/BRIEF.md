Build TWO distinctive, editorially impressive fictional client websites plus a root AethDesign portfolio index. Each client has three working pages, consistent navigation, meaningful local interactions and an authored visual identity. This is a portfolio-quality experience, not a generic hero + feature-card landing page. Businesses, prices and expeditions are illustrative; no invented testimonials, awards, clients, certifications or real operational claims.

A memorable system spanning editorial home, collection and specification planner.

Collection shows three fictional fixtures: `arc` ARC pendant EUR249.00, `line` LINE wall EUR189.00, `orbit` ORBIT table EUR329.00. ## Iteration and defect evidence — both subjects
Use `qa_check.py --owner lighting|expedition|integration --check-id SHORT_ID [--phase initial|verification|recheck] [--issue-id ID] -- COMMAND ARG...` for meaningful executable builder checks. It records bounded output, exit code and timing in the owner's check log. Log planned incomplete-scaffold checks as phaseinitial; they are not automatically defects. Repeated passing checks remain visible as reruns, not new defects. Preview bridge evidence is retained automatically.
For each concrete observed issue requiring correction, append one JSON object to the owner's `issues.jsonl` (clientfolder or integration folder): id,category(functional/runtime/resource/visual/accessibility),detected_by,summary,contract_or_visible_evidence,repro,fix_paths,status(open/fixed/blocked),recheck_id. Use append-only updates with sameid whenfixed; do not count a repeated report or manifestation as a new cause. A fix cycle is an observed issue→correction→targeted recheck; ordinary model/tool calls or initial construction are not cycles. Include screenshot evidence for visual issues when possible. Preserve failed checks and their outputs; do not overwrite history. Report issues honestly, including unresolved ones. External frozen grading is separate and cannot be repaired inside the recorded attempt afterward. Image retries are counted separately. Exact counts will be independently reconciled; unsupported attribution to a cheaper model is not proof.

Each client owner must deliver meaningful dependency-free Node regression tests at `lighting/tests/behavior.test.mjs` and `expedition/tests/behavior.test.mjs`. The configured quality verifier runs both files through `node --test`, as well as static routes/resources. Use pure contract logic or a small local DOM harness as appropriate; do not supply always-passing placeholders.
